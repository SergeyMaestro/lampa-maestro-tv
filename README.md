# Maestro TV — IPTV-плагин для Lampa

Ссылка для установки (Лампа → Настройки → Расширения → Добавить плагин):

```
https://cdn.jsdelivr.net/gh/SergeyMaestro/lampa-maestro-tv@main/maestro_tv.js
```

Как это работает: робот в GitHub Actions каждые 6 часов проверяет все потоки из открытых баз iptv-org (Россия, Казахстан, СНГ), оставляет только живые и складывает зеркала одного канала вместе. Плагин берёт готовый список из `data/channels.json` и при запуске канала сам перебирает зеркала.

Что умеет (v3):
- Пункт «ТВ и радио» в меню Лампы, слева разделы, справа список
- Русскоязычные категории + раздел «Зарубежные · English» + раздел «Радио» (Radio Browser)
- Телепрограмма: что идёт сейчас, прогресс, что дальше (iptvx.one, epg.pw)
- Поиск по названию канала, радиостанции или передачи, которая сейчас идёт
- Часто смотримые каналы поднимаются наверх, по желанию автозапуск последнего канала
- Раздел 18+ под PIN-кодом (меняется в настройках)
- Живое превью при наведении (включается в настройках)
- Зеркала: если поток не отвечает, плагин берёт следующий
- Избранное, недавние, скрытие каналов, свои M3U-плейлисты
